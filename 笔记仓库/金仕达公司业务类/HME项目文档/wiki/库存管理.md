# 库存管理

> 管理商品从入库到出库的全生命周期，包括库存估值、月结(EOM)和库存报表。

## 核心概念

| 概念 | 说明 | 详细文档 |
|---|---|---|
| 入库登记(Good Receipt) | 货物入库的登记操作，触发库存增加 | — |
| 出库登记(Good Release) | 货物出库的登记操作，触发库存减少 | — |
| 库存价值评估 | 对库存明细的价值评估，用于月结和报表 | [[库存价值评估报表方法分析]] |
| DetailEntrisValueEvaluation | 库存价值评估的核心方法 | [[DetailEntrisValueEvaluation-方法分析与二开指引]] |
| 月结(EOM) | 月末库存结算，计算期末库存估值 | — |
| 移库(Stock Transfer) | 仓库间的库存转移 | — |

## 业务流程

```
收货 → 入库登记 → 库存增加
                    ↓
              库存价值评估（DetailEntrisValueEvaluation）
                    ↓
              月结(EOM) → 期末库存估值快照
                    ↓
发货 → 出库登记 → 库存减少
```
