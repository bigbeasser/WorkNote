### 2.4 金属计算层 — InventoryValueEvaluationMetalCalcServiceImpl

**`enrichBatch(snapshots, sourceRows, psSnapshot)`**（第 106 行）：

```
enrichBatch()
│
├─ buildContext(psSnapshot, sourceRows)  ← 一次性加载公共数据
│   （包含：成品映射、Yield 规格 ID、LME/Bloomberg 结算价、Scorporo 行情等）
│
└─ for each (snapshot, sourceRow):
    └─ enrichOne(snapshot, row, psSnapshot, ctx, user, now)
        │
        ├─ 判断成品/原料（finishedProductMap）→ 设 articleCategory
        ├─ resolveCompositionProductId() → 确定成分产品
        ├─ listMetalSpecForComposition() → 查金属规格
        │   └─ 空 → fillMetalloOnly()（仅填金属信息，跳过计算）
        │
        ├─ 计算净重：netWeightKg = receivedKg × yieldRatio
        ├─ 遍历金属规格 → 计算各金属含量占比 → compositionTot
        ├─ 加载价格数据 → 计算各金属估值
        └─ 返回 InventoryValueEvaluationMetalCalcResult(snapshot + details)
```

**详细计算公式**（enrichOne 方法，第 150-273 行）：

#### 1. 净重计算（Net Weight）

```java
// 已入库数量（KG）
BigDecimal receivedKg = receivedQuantityKg(row);

// 净重 = 已入库数量 × Yield折率
BigDecimal netWeightKg = receivedKg × yieldRatio;
snapshot.setNetWeightKg(netWeightKg);
```

**字段说明**：
- `receivedKg`：已入库数量（从 `receivedQuantity` 字段转换，统一为 KG）
- `yieldRatio`：Yield 折率（从 `product_specification` 表查询）
- `netWeightKg`：净重（KG），用于后续金属成分计算

#### 2. 金属成分含量计算（Composition）

```java
// 遍历金属规格（排除 Yield）
for (spec in specList) {
    if (spec.specificationTypeId == yieldSpecId) continue;
    
    String metal = SpecificationTypeEnum.getElementById(specId);  // "CU", "NI", etc.
    BigDecimal content = spec.defaultValue;  // 含量占比（%）
    contentByMetal.put(metal, content);
    compositionTot += content;
}

snapshot.setCompositionTot(compositionTot);  // 总含量（应接近 100%）
snapshot.setChk(isCompositionValid(compositionTot) ? "OK" : "ERR");
```

**含量计算公式**：

| 金属 | 含量（%） | 来源 |
|------|----------|------|
| Cu | `cu = spec.defaultValue` | `product_specification` 表 |
| Ni | `ni = spec.defaultValue` | `product_specification` 表 |
| Sn | `sn = spec.defaultValue` | `product_specification` 表 |
| Al | `al = spec.defaultValue` | `product_specification` 表 |
| Zn | `zn = spec.defaultValue` | `product_specification` 表 |
| Pb | `pb = spec.defaultValue` | `product_specification` 表 |

#### 3. 金属量计算（Metal Quantity）

```java
for (metal in contentByMetal) {
    // 金属量 = 净重 × 含量占比
    BigDecimal metalKg = netWeightKg × contentByMetal.get(metal);
    metalKgMap.put(metal, metalKg);
    
    // 金属价格（EUR/KG）
    BigDecimal priceEurKg = resolveMetalPriceEurPerKg(finishedProduct, productId, postDate, spec, ctx, metal);
    priceEurPerKgMap.put(metal, priceEurKg);
}
```

**金属量计算公式**：

| 金属 | 金属量（KG） | 价格（EUR/KG） |
|------|-------------|---------------|
| Cu | `cuKg = netWeightKg × cu` | `priceEurPerKgMap.get("CU")` |
| Ni | `niKg = netWeightKg × ni` | `priceEurPerKgMap.get("NI")` |
| Sn | `snKg = netWeightKg × sn` | `priceEurPerKgMap.get("SN")` |
| Al | `alKg = netWeightKg × al` | `priceEurPerKgMap.get("AL")` |
| Zn | `znKg = netWeightKg × zn` | `priceEurPerKgMap.get("ZN")` |
| Pb | `pbKg = netWeightKg × pb` | `priceEurPerKgMap.get("PB")` |

#### 4. 主成分识别（Main Metal）

```java
// 主成分 = 含量最高的金属（排除 Yield）
String mainMetal = resolveMainMetal(contentByMetal);
snapshot.setMetalRef(mainMetal);
```

**主成分识别规则**：
- 从 `contentByMetal` 中找出含量最高的金属
- 用于后续的金属价值分配计算

#### 5. 金属价值分配（Metal Value Allocation）

```java
// 金属总价值（EUR）= 金属价值 + 应收/应付金额
BigDecimal metallo = row.getBaseCurMetalValue() + row.getBaseCurReceivableCDAmount();
snapshot.setMetalloEur(metallo);

// 按金属量和价格分配总价值
MetalValueAllocation allocation = computeMetalValueAllocation(
    mainMetal, metallo, metalKgMap, priceEurPerKgMap, SCALE);

Map<String, BigDecimal> metalValueEurMap = allocation.metalValueEurByMetal;
Map<String, BigDecimal> refNonMainMap = allocation.refNonMainByMetal;
```

**金属价值分配算法**：
- 主成分（mainMetal）承担大部分价值
- 其他金属按 `metalKg × priceEurPerKg` 比例分配
- 确保总价值 = `metalloEur`

#### 6. Greenlist 相关字段

```java
// 从 Greenlist 快照获取
GreenlistPriceSnapshot greenlistRow = resolveGreenlistSnapshot(finishedProduct, row, ctx);

// Greenlist 单价（EUR/KG）
BigDecimal greenListEurPerKg = greenListEurPerKgFromSnapshot(greenlistRow);
snapshot.setGreenListEurPerKg(greenListEurPerKg);

// LME 等价单价（EUR/KG）
BigDecimal lmeWithYieldEurPerKg = lmeEquivalentEurPerKgFromSnapshot(greenlistRow);
snapshot.setLmeWithYieldEurPerKg(lmeWithYieldEurPerKg);

// Unit Adder（EUR/KG）= Greenlist - LME
BigDecimal unitAdder = unitAdderEurPerKgFromSnapshot(greenlistRow);
snapshot.setUnitAdder(unitAdder);

// Weight Ref（KG）= 主成分的金属量
BigDecimal weightRef = resolveWeightRef(mainMetal, metalKgMap);
snapshot.setWeightRef(weightRef);

// Total Adder（EUR）= Unit Adder × Weight Ref
snapshot.setTotalAdder(unitAdder × weightRef);
```

**字段说明**：
- `greenListEurPerKg`：Greenlist 单价（EUR/KG）
- `lmeWithYieldEurPerKg`：LME 等价单价（EUR/KG），已考虑 Yield
- `unitAdder`：单位 Adder（EUR/KG）
- `weightRef`：主成分的金属量（KG）
- `totalAdder`：总 Adder（EUR）

#### 7. Margin 计算

```java
// 从 ForwardPrice 查询 Margin 价格
List<ForwardPriceRes> marginPrice = ctx.marginPrice;
Optional<ForwardPriceRes> any = marginPrice.stream()
    .filter(goods -> goods.getGoods().equals(row.getParentProductId()))
    .filter(legalEntity -> legalEntity.getPublicationId().equals(publicationMap.get(row.getLegalEntityId())))
    .findAny();

if (any.isPresent()) {
    snapshot.setUnitMargin(any.get().getMarketPriceValue());
} else {
    // 兜底：使用默认机构 3030L 的价格
    marginPrice.stream()
        .filter(goods -> goods.getGoods().equals(row.getParentProductId()))
        .filter(legalEntity -> legalEntity.getPublicationId().equals(publicationMap.get(3030L)))
        .findAny().ifPresent(s -> snapshot.setUnitMargin(s.getMarketPriceValue()));
}

// Total Margin = Unit Margin × Net Weight
snapshot.setTotalMargin(snapshot.getUnitMargin() × snapshot.getNetWeightKg());
```

**字段说明**：
- `unitMargin`：单位 Margin（EUR/KG），从 ForwardPrice 查询
- `totalMargin`：总 Margin（EUR）= Unit Margin × Net Weight
