# 应收应付与资金

> 管理发票生成、付款申请、信用证、银行流水和资金结算。

## 核心概念

| 概念 | 说明 | 详细文档 |
|---|---|---|
| 发票(Invoice) | 采购发票和销售发票的生成与管理 | — |
| Debit/Credit Note | 借贷项通知，用于价格调整和冲销 | — |
| 付款申请 | 向供应商付款的申请流程 | — |
| 信用证(Letter of Credit) | 银行信用担保的支付工具 | — |
| 索赔报告(Claim Report) | 质量/数量索赔的处理和SAP对接 | [[ClaimReport-SAP-Docking-Service]] |

## 业务流程

```
收发货完成 → 发票生成（临时发票 → 最终发票）
                ↓
          发票审批 → 推送 SAP
                ↓
          付款申请 / 收款登记
                ↓
          银行流水认领 → 结算完成
```
