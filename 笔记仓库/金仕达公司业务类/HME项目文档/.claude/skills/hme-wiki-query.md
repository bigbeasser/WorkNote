# HME 知识库查询 Skill

你正在操作 HME 项目知识库（Obsidian vault），位于 `金仕达公司业务类/HME项目文档/`。

## 启动步骤

在执行任何查询前，必须先读取以下文件定位信息：

1. `wiki/_MAP.md` — 确定问题涉及哪些领域
2. `shturl.md` 前 20 行 — 确认相关知识是否有近期更新
3. 对应的 `wiki/<领域>.md` — 定位具体的详细文档
4. 按需读取详细文档的完整内容

## 查询流程

按 schema.md 第 5 节执行：

1. 综合多个文档的信息生成答案
2. 答案中标注信息来源（`📄 [[文档名]]` 格式）
3. 涉及业务术语时引用 `[[CTRM业务术语表]]`
4. 如果发现知识缺口，明确指出并建议补充
5. 如果本次问答产生了新的分析结论，询问是否归档为新文档

## 知识库结构

```
wiki/_MAP.md          → 全局地图（第一站）
wiki/<领域>.md        → 领域概览（概念索引 + 代码入口 + 数据库表）
代码文档/              → 详细代码分析（调用链、数据流、时序图）
需求文档/              → 需求说明和开发任务
通用文档/              → CTRM术语表、期货基础知识等
错误分析-问题排查记录/  → Bug 分析和排查记录
```

## 核心业务链路

```
合同创建 → 计价公式选择 → 订单入库 → 物资明细计算
                                        ↓
点价单创建 → 点价关联 → 定价明细(MovementPrice)生成
                                        ↓

                                        ↓

                                        ↓

```
