# 定价明细（MovementPrice）价格字段计算逻辑文档

> [!info] 文档信息

> - **生成日期**：2026-06-10

> - **源码位置**：`MovementPriceServiceImpl.fillPriceInfo()` 第 2722-3182 行

## 一、核心价格字段概览

| 字段                   | 类型     | 中文名称 | 计算公式                                                  |

| -------------------- | ------ | ---- | ----------------------------------------------------- |

| `basePrice`          | Double | 基价   | 根据基价类型计算（见下文）                                         |

| `spread`             | Double | 升贴水  | 从现金流模型或商品行参数获取                                        |

| `otherCostPrice`     | Double | 其他费用 | 从现金流模型获取                                              |

| `settlementNetPrice` | Double | 总价   | `basePrice + spread + otherCostPrice`                 |

| `scorporoPrice`      | Double | 金属价  | 根据产品类型计算（见下文）                                         |

| `additionalPrice`    | Double | 附加价  | `settlementNetPrice / unitConversion - scorporoPrice` |

***

## 二、价值字段

| 字段           | 类型         | 中文名称 | 计算公式                                      |

| ------------ | ---------- | ---- | ----------------------------------------- |

| `totalValue` | BigDecimal | 总价值  | `settlementNetPrice × quantity`           |

| `metalValue` | BigDecimal | 金属价值 | `scorporoPrice × parentProductQuantity`   |

| `addedValue` | BigDecimal | 附加价值 | `additionalPrice × parentProductQuantity` |

***

## 三、本位币字段

| 字段                          | 类型         | 计算公式                                       |

| --------------------------- | ---------- | ------------------------------------------ |

| `exchangeRateBaseCur`       | Double     | 结算币种 → 本位币汇率                               |

| `priceBaseCur`              | Double     | `exchangeRateBaseCur × basePrice`          |

| `settlementNetPriceBaseCur` | Double     | `exchangeRateBaseCur × settlementNetPrice` |

| `additionalPriceBaseCur`    | Double     | `exchangeRateBaseCur × additionalPrice`    |

| `scorporoPriceBaseCur`      | BigDecimal | `exchangeRateBaseCur × scorporoPrice`      |

| `amountBaseCur`             | Double     | `quantity × settlementNetPriceBaseCur`     |

| `totalValueBaseCur`         | BigDecimal | `settlementNetPriceBaseCur × quantity`     |

## 四、基价（basePrice）计算逻辑

基价的计算取决于 `basicPriceFormulaId` 对应的基价类型：

### 4.1 固定价（BasicFixedPrice）

**数据源**：商品行参数 `pricingParams` 或 现金流模型 `CashflowModelValuesRes`

```text

优先级：

1. pricingParams["fixedPrice"] → 固定价（需单位转换）

2. cmv.settlementPrice → 结算价（需单位转换）

```

**scorporoDate** = `dailySettlementDate`（日结日期）

### 4.2 均价（BasicAveragePrice）

**数据源**：现金流定价行 `CashflowModelPricingDetailValuesRes`

**计算逻辑**：

1. 获取 `priceDate` 对应的定价行记录

2. 对每条记录的价格进行：

   - 单位转换

   - 币种转换（使用 `priceDate` 的汇率）

   - 乘以合约文本的 `defaultValue`（如有）

3. 累加所有价格得到 `basePrice`

**scorporoDate** = `priceDate`（计价日期）

**特殊场景**：

- 补充协议在计价期后：基价已在生成时计算（取已计价记录的平均值）

- 补充协议在计价期内：按 `priceDate` 取值

### 4.3 点价（BasicTriggeredPrice）

**数据源**：点价明细 `PriceTriggering`

**分支 1：现货价或特殊点价**

```text

条件：onSpotPrice=1/2 或 isSpecialPricing=true 或 dnCode 不为空

取值：

  - basePrice = pt.basePrice

  - spread = pt.spread

  - otherCostPrice = pt.otherExpenses

  - settlementNetPrice = pt.price

  - scorporoPrice = pt.metalPrice

  - additionalPrice = pt.additionalPrice

```

**分支 2：非现货价**

```text

从 ForwardPrice 表获取市场价格

计算：各成分价格 × 含量系数 × 收率

累加得到 basePrice

```

**scorporoDate** = `dailySettlementDate`（日结日期）

***

## 五、升贴水（spread）计算逻辑

**前提条件**：`calBasePrice = true`（非现货价点价）

### 5.1 百分比升贴水

**条件**：`pricingParams["spreadIsPercentage"] = "y"`

```text

spread = spreadValue × basePrice

```

### 5.2 固定升贴水

**数据源**：商品行参数 `pricingParams`

```text

1. 币种转换：spread × exchangeRate(spreadCurrencyId → currencyId)

2. 单位转换：spread / unitConversion(spreadUnitId → quantityUnitId)

```

***

## 六、其他费用（otherCostPrice）计算逻辑

**数据源**：现金流模型 `CashflowModelValuesRes.otherCostPrice`

**前提条件**：`calBasePrice = true`

***

## 七、总价（settlementNetPrice）计算逻辑

```text

settlementNetPrice = basePrice + spread + otherCostPrice

```

**方法**：`NumberUtil.add(10, basePrice, spread, otherCostPrice)`

***

## 八、金属价（scorporoPrice）计算逻辑

### 8.1 有金属价的产品

**条件**：`ProductFinancialAttributes` 中 `accountingGroup` 为 `Z002` 或 `Z003`

**数据源**：`riskUtil.getScoPrice()`

```text

scorporoDate 取值：

- 固定价：dailySettlementDate

- 均价：priceDate

- 点价：dailySettlementDate

获取逻辑：

1. 按 scorporoDate 查询金属价

2. 如果为空 且 onSpotPrice=2 且 scorporoDate ≤ 当前日结日期

   → 向前查询最多 10 天

```

### 8.2 无金属价的产品

```text

scorporoPrice = settlementNetPrice / unitConversion

```

***

## 九、附加价（additionalPrice）计算逻辑

```text

additionalPrice = (settlementNetPrice / unitConversion) - scorporoPrice

```

其中 `unitConversion` 是 `quantityUnitId` → `parentProductQuantityUnitId` 的转换系数

***

## 十三、关键公式总结

> [!formula] 核心计算公式

> ```

> 总价 = 基价 + 升贴水 + 其他费用

>      settlementNetPrice = basePrice + spread + otherCostPrice

> 

> 附加价 = (总价 / 单位转换系数) - 金属价

>        additionalPrice = (settlementNetPrice / unitConversion) - scorporoPrice

> 

> 总价值 = 总价 × 数量

>        totalValue = settlementNetPrice × quantity

> 

> 金属价值 = 金属价 × 父商品数量

>          metalValue = scorporoPrice × parentProductQuantity

> 

> 附加价值 = 附加价 × 父商品数量

>          addedValue = additionalPrice × parentProductQuantity

> ```

***

## 十四、注意事项

> [!warning] 重要提示

> 1. **FIX 类型不计算价格**：`priced=0` 的记录在 `fillPriceInfo` 中会被跳过

> 2. **RI-/CC- 取反逻辑**：冲销记录的金额字段在原记录基础上取反

> 3. **汇率获取失败处理**：如果按 `priceDate` 获取不到汇率，会向前查询最近的工作日

> 4. **金属价向前查询**：`onSpotPrice=2` 时，如果当天没有金属价，会向前查询最多 10 天

> 5. **单位转换**：涉及多次单位转换，包括基价、升贴水、数量等

> 6. **币种转换**：均价计算时需要对每条定价行进行币种转换

> 7. **IC 交易特殊处理**：`intercompany` 为 BTO/BTS 的记录走 `fillPriceInfoForIC` 逻辑
