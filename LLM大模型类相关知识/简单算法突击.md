# 简单算法突击





- **数组 & 字符串操作**（占比最高）
- **哈希表（HashMap）应用**
- **双指针 / 滑动窗口**
- **简单排序 & 查找（二分查找）**
- **栈 & 队列（括号匹配、计算器等）**
- **递归 & 简单回溯（如子集、排列）**
- **链表基础操作（反转、合并、环检测）**
- **树的遍历（DFS/BFS、二叉搜索树）**







## 1. 数组 & 字符串（最优先刷）

**目标**：掌握遍历、边界处理、Java 数组 / String 常用 API

**必刷题**：

1. 两数之和（简单，哈希表 + 数组综合）
2. 移除元素（简单，原地修改）
3. 合并两个有序数组（简单，双指针 + 数组）
4. 最长公共前缀（简单，字符串遍历）
5. 有效的字母异位词（简单，字符串 + 哈希思想）
6. 字符串相加（中等，大数加法）
7. 最长回文子串（中等，面试高频）

**面试常问**：数组扩容、String 不可变、时间 / 空间复杂度

## 2. 哈希表（HashMap 必问）

**目标**：会用 HashMap 解决去重、计数、映射问题

**必刷题**：

1. 两数之和

## 3. 双指针 / 滑动窗口

**目标**：学会**一次遍历**解决问题，降低时间复杂度

**必刷题**：

1. 反转字符串（简单）
2. 移动零（简单）
3. 盛最多水的容器（中等）
4. 无重复字符的最长子串（滑动窗口，高频）
5. 最小覆盖子串（困难，了解思路即可）



### 滑动窗口

给定一个含有 `n` 个正整数的数组和一个正整数 `target`，找出该数组中满足其和 `≥ target` 的长度最小的**连续子数组**，并返回其长度。如果不存在符合条件的子数组，返回 `0`。

示例：

- 输入：`target = 7, nums = [2,3,1,2,4,3]`
- 输出：`2`（子数组 `[4,3]` 和为 7，长度最小）

### 命令及场景总结

| 场景                                   | 命令                                                         | 说明                                                         |
| -------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 查异常堆栈，获取完整上下文信息         | `grep -A 50 "java.lang.NullPointerException" a.log`          | 使用 `-A` 参数显示匹配行之后的 50 行，用于查找 `NullPointerException` 异常堆栈 |
| 查异常堆栈，分页查看                   | `grep -A 50 "java.lang.NullPointerException" a.log | less`   | 结合 `less` 分页查看包含 `NullPointerException` 及后续 50 行的日志信息 |
| 实时监控新日志                         | `tail -f a.log | grep -A 50 "java.lang.NullPointerException"` | 实时监控 `a.log` 文件新增内容，显示包含 `NullPointerException` 及后续 50 行的日志 |
| 查找当前目录所有 `.log` 文件中的异常   | `grep -H -A 50 "java.lang.NullPointerException" *.log`       | 在当前目录下查找所有以 `.log` 结尾的文件中包含 `NullPointerException` 及后续 50 行的日志，`-H` 参数打印文件名 |
| 查找 `.gz` 压缩日志中的异常            | `zgrep -H -A 50 "java.lang.NullPointerException" *.gz`       | 查找当前目录下所有 `.gz` 压缩日志文件中包含 `NullPointerException` 及后续 50 行的日志，`zgrep` 专门处理 `.gz` 文件，`-H` 参数打印文件名 |
| 统计单个日志文件中异常出现的次数       | `grep -c "java.lang.NullPointerException" a.log`             | 统计 `a.log` 文件中 `NullPointerException` 出现的次数        |
| 统计所有 `.log` 文件中异常出现的总次数 | `grep -c "java.lang.NullPointerException" *.log`             | 统计当前目录下所有 `.log` 文件中 `NullPointerException` 出现的总次数 |
| 查看异常前后上下文                     | `grep -C 25 "java.lang.NullPointerException" a.log`          | 使用 `-C` 参数显示匹配行上下共 25 行，查看 `NullPointerException` 前后的上下文 |

### 其他常用 `grep` 参数说明

| 参数   | 作用                   |
| ------ | ---------------------- |
| `-B N` | 显示匹配行之前的 N 行  |
| `-A N` | 显示匹配行之后的 N 行  |
| `-C N` | 显示匹配行上下共 N 行  |
| `-i`   | 忽略大小写             |
| `-H`   | 显示匹配的文件名       |
| `-r`   | 递归搜索目录下所有文件 |
