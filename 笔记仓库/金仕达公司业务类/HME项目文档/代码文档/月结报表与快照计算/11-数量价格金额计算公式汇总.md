# 月结报表数量价格金额计算公式汇总

> 本文档汇总所有月结报表和快照计算中的**数量、价格、金额**字段的计算公式，方便快速查阅。

---

## 一、采购库存定价快照（①）

### 1.1 数量字段

| 字段 | 计算公式 | 说明 |
|------|---------|------|
| `pricedButNotInStockKg` | 从报表数据读取 | 已定价未入库量（KG） |
| `pricedButNotInAmount1` | 从报表数据读取 | 已定价未入库金额（结算币种） |
| `quantityAlreadyPricedKg` | 从报表数据读取 | 已定价量（KG） |
| `quantityAlreadyKg` | 从报表数据读取 | 已入库量（KG） |
| `cuKg` | `cu × yieldMutQuantity` | CU 金属量（KG） |
| `niKg` | `ni × yieldMutQuantity` | NI 金属量（KG） |
| `snKg` | `sn × yieldMutQuantity` | SN 金属量（KG） |
| `agKg` | `ag × yieldMutQuantity` | AG 金属量（KG） |
| `alKg` | `al × yieldMutQuantity` | AL 金属量（KG） |
| `znKg` | `zn × yieldMutQuantity` | ZN 金属量（KG） |
| `pbKg` | `pb × yieldMutQuantity` | PB 金属量（KG） |

**中间变量**：
```
yieldValue = Yield折率（从 product_specification 表查询）
yieldMutQuantity = pricedButNotInStockKg × yieldValue
```

### 1.2 价格字段

| 字段 | 计算公式 | 说明 |
|------|---------|------|
| `forex` | 从 `forward_price` 表查询 | 汇率（结算币 → 本位币） |
| `converQuantityRate` | 从 `riskUnitConversionUtil` 查询 | 质量单位转换率（吨 → KG） |
| `greenlistPrice` | `LmeForGreenlist ÷ converQuantityRate` | Greenlist 单价（EUR/KG） |
| `lmeEquivalent` | `LmeEquivalent ÷ converQuantityRate` | LME 等价单价（EUR/KG） |
| `adder` | `Adder ÷ converQuantityRate` | Adder 单价（EUR/KG） |

### 1.3 金额字段

| 字段 | 计算公式 | 说明 |
|------|---------|------|
| `baseCurrencyAmountCac` | `pricedButNotInAmount1 ÷ forex` | 本位币金额（CAC） |
| `baseCurrencyAmountDiff` | `baseCurrencyAmountCac - pricedButNotInAmount1` | 本位币金额差异 |
| `netias` | `baseCurrencyAmountCac - (adder × pricedButNotInStockKg)` | NETIAS（本位币） |
| `netiasComm` | `pricedButNotInAmount1 - (adder × pricedButNotInStockKg)` | NET COMM（结算币） |
| `netiasCommDiff` | `netiasComm - baseCurrencyAmountCac` | NETIAS 与 NET COMM 的差异 |

## 五、Greenlist价格快照（⑤）

### 5.1 金属占比字段

| 字段 | 计算公式 | 说明 |
|------|---------|------|
| `cuPct` / `cuPctFactory` | 从 `product_specification` 表查询 | CU 成分占比（%） |
| `znPct` / `znPctFactory` | 从 `product_specification` 表查询 | ZN 成分占比（%） |
| `pbPct` / `pbPctFactory` | 从 `product_specification` 表查询 | PB 成分占比（%） |
| `alPct` / `alPctFactory` | 从 `product_specification` 表查询 | AL 成分占比（%） |
| `snPct` / `snPctFactory` | 从 `product_specification` 表查询 | SN 成分占比（%） |
| `niPct` / `niPctFactory` | 从 `product_specification` 表查询 | NI 成分占比（%） |
| `yieldPctFactory` | 从 `product_specification` 表查询 | Yield 折率（%） |

### 5.2 LME 价格字段

| 字段 | 计算公式 | 说明 |
|------|---------|------|
| `lmeCu` | `resolveLmeByElement("CU") × usdEurExchangeRate` | LME CU 价格（EUR/吨） |
| `lmeZn` | `resolveLmeByElement("ZN") × usdEurExchangeRate` | LME ZN 价格（EUR/吨） |
| `lmePb` | `resolveLmeByElement("PB") × usdEurExchangeRate` | LME PB 价格（EUR/吨） |
| `lmeAl` | `resolveLmeByElement("AL") × usdEurExchangeRate` | LME AL 价格（EUR/吨） |
| `lmeSn` | `resolveLmeByElement("SN") × usdEurExchangeRate` | LME SN 价格（EUR/吨） |
| `lmeNi` | `resolveLmeByElement("NI") × usdEurExchangeRate` | LME NI 价格（EUR/吨） |

### 5.3 核心价格字段

| 字段 | 计算公式 | 说明 |
|------|---------|------|
| `lmeForGreenlist` | 见下方分类公式 | LME 基准价格（EUR/吨） |
| `lmeEquivalent` | `Σ(pctFactory × lme) × yieldPctFactory` | LME 等价价格（EUR/吨） |
| `averagePremiumDiscount` | `totalDiscount ÷ receiptQuantityTo` | 月均折扣/溢价（EUR/吨） |
| `greenlistPriceEurPerTo` | `手工价` 或 `lmeForGreenlist + averagePremiumDiscount` | Greenlist 单价（EUR/吨） |
| `adder` | `greenlistPriceEurPerTo - lmeEquivalent` | Adder（EUR/吨） |

**LmeForGreenlist 分类公式**：

```java
// 1. Alloy/半成品/成品
if (articleCategory in ["Z003", "Z002", "Alloy"]) {
    lmeForGreenlist = allPriceCashMap.get(curveId);  // 合约 Cash 价格
}

// 2. 原材料 - New Metal (family=000)
if (articleCategory == "Z001" && family == "000") {
    lmeForGreenlist = 
        cuPct × lmeCu + znPct × lmeZn + pbPct × lmePb + 
        alPct × lmeAl + snPct × lmeSn + niPct × lmeNi;
}

// 3. 原材料 - Scrap (family=040)
if (articleCategory == "Z001" && family == "040") {
    lmeForGreenlist = 
        cuPct × lmeCuLowest + znPct × lmeZnLowest + pbPct × lmePbLowest + 
        alPct × lmeAlLowest + snPct × lmeSnLowest + niPct × lmeNiLowest;
}
```

| 字段 | 计算公式 |

| `znKg` | `netWeightKg × zn` |

| `lmeWithYieldEurPerKg` | 从 Greenlist 快照查询 | LME 等价单价（EUR/KG） |

| 字段 | 计算公式 | 说明 |

**金属子表字段**：

| 字段 | 计算公式 | 说明 |
|------|---------|------|

## 十、年度库存金属成本汇总表（⑩）

### 10.1 数量字段

| 字段 | 计算公式 | 说明 |
|------|---------|------|
| `totalQuantityKg` | `SUM(detail.quantityKg)` | 年度累计金属量（kg） |
| `totalNetWeightKg` | `SUM(snapshot.netWeightKg)` | 年度累计净重（kg） |

### 10.2 金额字段

| 字段 | 计算公式 | 说明 |
|------|---------|------|
| `totalMetalValueEur` | `SUM(detail.metalValueEur)` | 年度累计估值（EUR） |
| `totalAdderEur` | `SUM(snapshot.totalAdder)` | 年度累计 Adder（EUR） |
| `totalMarginEur` | `SUM(snapshot.totalMargin)` | 年度累计 Margin（EUR） |

**聚合公式**：

```sql
SELECT 
    legalEntityId, businessSegmentId, specificationTypeId,
    SUM(quantityKg) AS totalQuantityKg,
    SUM(metalValueEur) AS totalMetalValueEur,
    SUM(netWeightKg) AS totalNetWeightKg,
    SUM(totalAdder) AS totalAdderEur,
    SUM(totalMargin) AS totalMarginEur
FROM evaluation_of_detaile_entries_value_snapshot snapshot
JOIN evaluation_of_detaile_entries_value_snapshot_detail detail 
    ON snapshot.id = detail.snapshotId
WHERE YEAR(accountingDate) = {year}
GROUP BY legalEntityId, businessSegmentId, specificationTypeId
```

## 十一、公共计算公式

### 11.1 汇率换算

```java
// 结算币 → 本位币
baseCurrencyAmount = settlementCurrencyAmount ÷ forex

// 本位币 → EUR（如果需要）
eurAmount = baseCurrencyAmount × baseToEurRate
```

### 11.2 质量单位转换

```java
// 吨 → KG
kgAmount = tonAmount × converQuantityRate

// 价格转换：EUR/吨 → EUR/KG
pricePerKg = pricePerTon ÷ converQuantityRate
```

### 11.3 金属成分拆分

```java
// 1. 计算折后量
yieldMutQuantity = quantity × yieldValue

// 2. 计算各金属量
for each metal (Cu/Ni/Sn/Al/Zn/Pb):
    metalKg = metalPct × yieldMutQuantity

// 3. 计算各金属价值
metalValueEur = metalKg × priceEurPerKg
```

### 11.4 Adder 计算

```java
// 单位 Adder
adder = greenlistPrice - lmeEquivalent

// 总 Adder
totalAdder = adder × weightRef
```

### 11.5 Margin 计算

```java
// 总 Margin
totalMargin = unitMargin × netWeightKg
```

## 十三、精度要求

所有金额/比率字段统一保留 **5位小数**，使用 `RoundingMode.HALF_UP` 舍入模式。

```java
.setScale(5, RoundingMode.HALF_UP)
```
