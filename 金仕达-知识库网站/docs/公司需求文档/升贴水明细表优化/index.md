## 一、需求背景

优化升贴水明细表（Premium and Discount Detail），**不要重构，原来字段逻辑不动**。

- 统计对象：**已推送 SAP 的采购合同**（包括现货订单和长协订单）
- 以商品行为维度，筛选出商品为**原材料**的，展示在列表
- 只查询**含有升贴水的订单行**
- 显示所有计价类型的订单行

## 四、LML 金属值计算与欧元转换

### 4.1 求 LML 某金属值

参考采购周报报表的 LML 金属价值逻辑：

- **行情日期** = 合同签订日期
- **交易小结** = 0
- **标记** = Lowest
- **合约文本** = 商品定义质检类型的 Fixation 合约文本
- 取的行情值即为 LML 某金属值

按商品定义 → 质检类型的 Fixation 比例去加权汇总：

```
LML 金属值 = CU占比 × LML_CU + ZN占比 × LML_ZN + PB占比 × LML_PB + ...
```

**示例**：`CU 50% × LML_CU + ZN 40% × LML_ZN + PB 10% × LML_PB`

### 4.2 转欧元

使用美元转欧元汇率：

- 查询 USD-EUR 汇率行情值
- 将 LML 金属值（美元）除以汇率行情值，转换为欧元

### 4.3 汇率取值规则

- 使用订单行 → 计价公式页面 → 升贴水页面所选市场的汇率
- 若查不到该市场的汇率，使用 **Bloomberg 汇率**
- 查得到就用升贴水市场的汇率
- 美元转欧元：看选择乘法（USD-EUR）还是除法（EUR-USD）
  - 乘法示例：`USD-EUR: 0.8333`，即 1 美元 ≈ 0.8333 欧元

!!! warning "当天汇率取不到时的处理"
    - **原逻辑**：当天汇率取不到且币种不是欧元必须转汇率的，该数据为空
    - **修改后**：取不到则取**前一天的汇率**

### 4.4 质检类型取值规则

| 问题 | 处理方式 |
|------|---------|
| 质检类型本身没有（半成品 5 开头、产成品 6 开头） | 取**父商品** |
| 没有 Fixation 的原材料 | 用**业务机构-工厂**的逻辑 |
| 废料（原材料，只有一个质检类型，法国，比例 1，是否计价未勾选） | 销售向才有废料，采购向不存在此情况 |
