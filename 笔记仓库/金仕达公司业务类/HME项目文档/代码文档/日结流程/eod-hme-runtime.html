日结批处理如何一步步跑完

从页面接口 PUT /api/jobs/execByTaskName/EOD-hme 启动， 经 Quartz 与 Activiti 编排，每个 Delegate 只做自己的 process， 最终由 Finish 驱动多机构循环。

总览：触发到结束

形状表示类型：椭圆为起止，矩形为步骤，菱形为决策。焦点步骤用强调色标出。

单步模板：开始执行 / 执行失败从哪来

所有 HME*EODDelegate 共享 BaseActivityDelegate.execute。 子类只需实现 process；注解文案写入任务日志的「任务名」。

以 Brass Scorporo 为例：日志里的 START/END 是类内 StopWatch；「开始执行/执行结束」来自基类；「完成/失败」来自 EODServiceImp 业务日志。

ENTRY

怎么触发

  • PUT /api/jobs/execByTaskName/EOD-hme
  • 硬编码 JobId=16，流程 key=inside_1ilb
  • 价校验失败则整次不启动

PATTERN

每步只干一件事

  • Delegate 薄封装 → 调一个 Service 方法
  • 开关来自对接配置 EodControl
  • 上下文从 Redis EOD:* 灌入

LOOP

多机构如何串

  • Finish 后再次 execution 同一 Job
  • 从 EOD:LegalEntityIds pop 下一机构
  • 队列空 → Status=SUCCEED
