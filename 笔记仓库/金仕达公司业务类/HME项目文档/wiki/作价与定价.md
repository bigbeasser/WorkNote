# 作价与定价

> 管理大宗商品的价格确定机制：从合同中选择计价公式，到点价确定基价，再到生成定价明细(MovementPrice)的完整链路。

## 核心概念

| 概念 | 说明 | 详细文档 |
|---|---|---|
| 计价公式(Pricing Formula) | 合同中决定金属价格的规则，支持多层级组合（基价+升贴水+加工费+附加价） | [[pricing-formula-developer-guide]] |
| 点价(Fixation) | 在约定期间内确定实际价格的操作，分为我方点价和对方点价 | [[点价单创建流程]] |
| 定价明细(MovementPrice) | 每次定价生成的明细记录，是日结和结算的核心数据 | [[定价明细MovementPrice生成逻辑文档]] |
| 计价量模型 | MovementPrice 的生命周期管理，从生成到日结消费 | [[movement-price-lifecycle]] |
| 升贴水(Premium/Discount) | 在基价基础上的加减价，可以是固定值或百分比 | [[pricing-formula-developer-guide]] |
| 均价(Average Price) | 按期间均价计价的方式 | [[pricing-formula-developer-guide]] |
| 点价关联 | 将点价记录与收发货明细关联的操作 | [[点价单和定价明细的计算]] |

## 业务流程

```
合同创建 → 选择计价公式（绑定到合同行 physical_deal_line）
    ↓
    ├── 固定价(BasicFixedPrice) → 直接生成 MovementPrice
    ├── 点价(BasicTriggeredPrice) → 创建点价单 → 点价关联 → 生成 MovementPrice
    └── 均价(BasicAveragePrice) → 按期间均价 → 生成 MovementPrice
                                        ↓
                              MovementPrice 参与日结计算
```
