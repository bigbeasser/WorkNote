## 排查经验总结

!!! warning "通用排查步骤"
    1. **检查 Redis 状态**：`EOD:Status` 当前值、控制标志是否正确
    2. **查看任务跟踪表**：`TaskProcessingInfo` 和 `TaskProcessingInfoLogs` 记录
    3. **检查 Activiti 流程**：流程实例状态、当前节点、变量值
    4. **查看外部系统日志**：CRM/SAP 推送请求和响应
    5. **检查定时任务配置**：QuartzJob 的 beanName、methodName、params
