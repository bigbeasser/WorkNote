# 衍生品与风险管理

> 管理期货持仓、日结(EOD)结算、现金流模型和市场风险监控。

## 核心概念

| 概念 | 说明 | 详细文档 |
|---|---|---|
| 日结(EOD/End of Day) | 每日交易结束后的结算流程，更新持仓和盈亏 | [[ExecuteHMEFlowTask-日结执行链路深度分析与修复指引]] |
| ExecuteHMEFlowTask | 日结的核心执行任务 | [[ExecuteHMEFlowTask调用链分析文档]] |
| 现金流模型(CashFlowModel) | 管理未来现金流的预测和结算 | — |
| 持仓(Position) | 期货和实货的持仓统计 | — |
| 采购库存定价表 | 基于 MovementPrice 聚合的库存定价报表 | [[pricing-table-calculation-analysis]] |

## 业务流程

```
交易发生（实货/期货）
    ↓
日结触发（ExecuteHMEFlowTask）
    ↓
├── 更新持仓统计
├── 消费 MovementPrice → 更新现金流模型
├── 计算浮动盈亏
└── 生成日结日志
    ↓
采购库存定价表生成
```
